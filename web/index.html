Installer le favori

À bord, le portail du train ne laisse pas une page extérieure lire ses données (aucun en-tête CORS). Le favori contourne la limite : lancé sur la page du portail, il y affiche le widget, qui lit alors l'API depuis la même origine.

SNCF Wifi

Ordinateur : glissez le bouton violet dans la barre de favoris.

iPhone / iPad (Safari) : ajoutez cette page à vos favoris (bouton Partager → Ajouter un signet), nommez-le « SNCF Wifi », puis modifiez le signet et remplacez son adresse par le code copié.

Android (Chrome) : même principe ; à bord, tapez « SNCF Wifi » dans la barre d'adresse et choisissez le favori.

Ensuite, dans le train : ouvrez wifi.sncf (ou le portail du train), puis lancez le favori. Le relancer masque ou réaffiche le widget.

Si rien ne s'affiche, le portail refuse peut-être les scripts venus d'ailleurs : essayez le favori autonome, qui embarque tout le code.

Réseaux pris en charge
  • WiFi SNCF (TGV INOUI, Intercités) : vitesse, desserte, retard et cause, WiFi, données.
  • WiFi TGV Lyria : vitesse, desserte (horaires théoriques), position, WiFi.
  • WIFIonICE : vitesse, desserte avec voies, retards, prévision de connexion.
  • WiFi Eurostar : vitesse, position, liens montants, données (pas de desserte).

Version web du widget macOS SNCFWifi. Aucune donnée ne quitte votre appareil : seules les API du train sont appelées.
